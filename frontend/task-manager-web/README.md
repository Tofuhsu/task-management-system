# Task Manager Web

Vue 3 and TypeScript frontend for the Task Management System. See the [root README](../../README.md) for full setup and API documentation.

```bash
cp .env.example .env.local
npm ci
npm run dev
```

Available commands:

- `npm run dev` starts the Vite development server.
- `npm run type-check` checks Vue and TypeScript types.
- `npm run build` type-checks and creates the production bundle.
- `npm run preview` serves the production bundle locally.
